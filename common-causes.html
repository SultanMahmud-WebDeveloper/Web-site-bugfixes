Diagnosis guide

Common causes of critical errors & site bugs

Most broken sites come down to a handful of causes. Pick a category to see the cause, the symptoms you will notice and the quick fix.

Common Causes & Fixes

PHP & Fatal

Faulty functions.php edit

Cause: A missing semicolon or bracket, or a call to a function that does not exist.

  • White Screen of Death
  • "There has been a critical error"
  • Locked out of wp-admin

Quick fix: Read debug.log, fix the exact line, then re-test.

PHP & Fatal

PHP version mismatch

Cause: Hosting upgraded PHP, but an old theme or plugin still uses removed code.

  • Fatal error after a host update
  • Warnings and notices on every page
  • Deprecated function messages

Quick fix: Update the code to be PHP-compatible, or roll the PHP version back temporarily.

PHP & Fatal

Memory limit exhausted

Cause: A heavy plugin, import or loop uses more memory than the server allows.

  • "Allowed memory size exhausted"
  • Page builder fails to load
  • Imports or backups stop halfway

Quick fix: Raise WP_MEMORY_LIMIT and find the plugin that is eating memory.

PHP & Fatal

Server & .htaccess problems

Cause: A corrupted .htaccess file, wrong file permissions or a server timeout.

  • 500 Internal Server Error
  • Every page except the home page gives 404
  • Random timeouts

Quick fix: Regenerate .htaccess, reset permissions and check server error logs.

CSS & Layout

Mobile horizontal overflow

Cause: An element with a fixed width or negative margin is wider than the phone screen.

  • Page scrolls sideways on mobile
  • Content cut off on the right
  • Zoomed-out look on phones

Quick fix: Find the wide element and give it max-width: 100% with proper wrapping.

CSS & Layout

Overlapping header & sections

Cause: Conflicting z-index, fixed heights or broken flex/grid rules.

  • Menu covers the hero section
  • Text sits on top of images
  • Columns stack in the wrong order

Quick fix: Replace fixed heights with flex/grid and set a clear stacking order.

Plugins & Theme

Plugin update conflict

Cause: Two plugins load clashing code, or one needs a newer version of another.

  • Site breaks right after an update
  • Features stop working in wp-admin
  • JavaScript errors in the console

Quick fix: Deactivate plugins one by one to find the clash, then patch or replace it.

Plugins & Theme

Theme update breaks templates

Cause: Edits made directly in the parent theme are overwritten, or templates are outdated.

  • Custom changes disappear
  • Layout looks different after update
  • Missing template or widget areas

Quick fix: Move changes into a child theme and update the old templates.

WooCommerce

Cart & checkout bugs

Cause: A script conflict, a bad custom fee snippet or a payment plugin error.

  • Place Order button does nothing
  • Cart total or shipping is wrong
  • Customers cannot pay

Quick fix: Trace the failing hook or script, fix it, then run a full test order.

WooCommerce

Forms & AJAX failures

Cause: A JavaScript error, blocked AJAX request or email settings problem.

  • Form spins forever or shows an error
  • No email notifications arrive
  • Console shows red errors

Quick fix: Fix the script error, check AJAX responses and set up reliable SMTP.
